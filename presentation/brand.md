# Стиль

Всё, что нужно задать в Canva до сборки слайдов.

## Цвета

| Роль | HEX | Где используется |
| --- | --- | --- |
| Фон | | подложка слайда |
| Текст | | заголовки и основной текст |
| Акцент | | цифры, выделения, кнопки |
| Второстепенный | | подписи, сноски |

## Шрифты

- Заголовки: _шрифт, кегль_
- Основной текст: _шрифт, кегль_

## Тон

- _формальный / разговорный_
- _плотный текстом / крупные цифры и минимум слов_

## Ограничения

- Логотип: _есть в assets/ или нет_
- Готовый brand kit в Canva: _есть / нет_
