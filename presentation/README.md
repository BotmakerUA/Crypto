# Презентация

Рабочая папка для подготовки презентации. Порядок работы: сначала текст и
структура здесь, в markdown, потом сборка дизайна в Canva.

## Структура

| Файл | Что внутри |
| --- | --- |
| `outline.md` | Скелет: цель, аудитория, список слайдов одной строкой каждый |
| `slides.md` | Полный контент по слайдам — заголовки, тезисы, заметки для спикера |
| `brand.md` | Цвета, шрифты, тон — то, что задаётся в Canva перед сборкой |
| `assets/` | Логотипы, скриншоты, графики — всё, что уходит в Canva как картинки |

## Процесс

1. Заполняем `outline.md` — согласуем структуру до того, как писать тексты.
2. Раскрываем каждый слайд в `slides.md`.
3. Фиксируем стиль в `brand.md`, кладём картинки в `assets/`.
4. Собираем деку в Canva по `slides.md`, ссылку на дизайн пишем ниже.
