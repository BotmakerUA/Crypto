# Crypto

This project relies on a few secrets that should be provided via
environment variables:

* `API_KEY` – your exchange API key
* `API_SECRET` – the corresponding API secret
* `TELEGRAM_TOKEN` – token for your Telegram bot
* `TELEGRAM_CHAT_ID` – chat ID for bot notifications

Export these variables before running any scripts, for example:

```bash
export API_KEY="..."
export API_SECRET="..."
export TELEGRAM_TOKEN="..."
export TELEGRAM_CHAT_ID="123456789"
```
