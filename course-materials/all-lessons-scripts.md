# УРОК 3: Мистецтво правильних запитів (Промпт-інженерія)

"Вітаю! Якщо ви вже користуєтеся ChatGPT, напевно помітили: іноді він дає чудові відповіді, а іноді - не зовсім те, що потрібно.

Секрет у тому, ЯК ви ставите питання!

Сьогодні ви навчитеся промпт-інженерії - мистецтву формулювання ідеальних запитів. Це як магічне заклинання для ШІ! ✨"

### [2:00-7:00] 5 ПРИНЦИПІВ ГАРНОГО ПРОМПТА

**ПРИНЦИП 1: Будьте конкретними**

❌ Поганий промпт: "Розкажи про здоров'я"
✅ Хороший промпт: "Дай 5 простих порад для покращення сну для людини 35 років з сидячою роботою"

**ПРИНЦИП 2: Вказуйте контекст**

❌ Поганий: "Напиши лист"
✅ Хороший: "Напиши офіційний лист відмови клієнту, зберігаючи доброзичливий тон. Причина: ми не надаємо таку послугу."

**ПРИНЦИП 3: Визначайте формат**

❌ Поганий: "Інформація про вітаміни"
✅ Хороший: "Створи таблицю: вітамін | продукти | добова норма | нестача симптоми. Для дорослої людини."

**ПРИНЦИП 4: Вказуйте роль**

❌ Поганий: "Допоможи з резюме"
✅ Хороший: "Діє як HR експерт з 10-річним досвідом. Покращ моє резюме для позиції [назва]."

**ПРИНЦИП 5: Просіть крок за кроком**

❌ Поганий: "Як навчитися фотографії?"
✅ Хороший: "Створи покроковий 4-тижневий план навчання фотографії на смартфоні. Щодня 20 хвилин практики."

### [7:00-15:00] ШАБЛОНИ ЗАПИТІВ ЯКІ ЗАВЖДИ ПРАЦЮЮТЬ

**ШАБЛОН 1: Роль + Завдання + Контекст + Формат**
```
"Діє як [роль експерта],
допоможи мені [конкретне завдання],
враховуючи [важливий контекст],
надай результат у форматі [як подати]."
```

Приклад:
```
"Діє як дієтолог,
створи меню на тиждень для схуднення,
враховуючи: вегетаріанець, алергія на горіхи, бюджет 1500 грн,
надай у форматі таблиці: день | сніданок | обід | вечеря | калорії."
```

**ШАБЛОН 2: Проблема → Рішення → Дія**
```
"Моя проблема: [опис ситуації]
Що я вже спробував: [що робили]
Мені потрібно: [очікуваний результат]
Запропонуй 3 конкретні кроки що робити далі."
```

**ШАБЛОН 3: Аналіз + Порівняння**
```
"Порівняй [варіант A] та [варіант B]
для [моя ситуація].
Надай: плюси, мінуси, ціна, підходить чи ні.
Формат: таблиця."
```

**ШАБЛОН 4: Навчання**
```
"Навчи мене [навичка].
Мій поточний рівень: [початківець/середній].
Часу маю: [скільки] на день.
Створи [період] план з конкретними завданнями."
```

**ШАБЛОН 5: Творчість + Обмеження**
```
"Запропонуй [кількість] ідей для [що потрібно].
Обмеження: [бюджет/час/умови].
Критерії: [що важливо].
Оціни кожну ідею за шкалою 1-10."
```
